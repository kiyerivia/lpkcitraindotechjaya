# lpkcitraindotechjaya
Aplikasi pembelajaran bahasa Jepang untuk LPK CIJ dengan fitur kelas online via Zoom, materi pembelajaran interaktif, latihan soal, progress belajar, dan paket pendaftaran siswa. Dirancang dengan UI modern untuk mendukung proses belajar bahasa Jepang serta persiapan kerja dan karier di Jepang.
